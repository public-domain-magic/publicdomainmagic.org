# Plan 005: Magic Bounded Context (Model Layer)

## Context

Magic is the public-facing domain context: the conjuring semantics (the magical arts,
effects, tricks, categories) powering search/browse, the access rules for downloads, and
the commerce hooks (affiliate links, the *Greater Magic* countdown hype). All data is
hand-entered by Librarians at launch. It references Catalog by ID; the FRBR mapping is the
context map at `.agents/skills/frbr-wemi/references/magic.md` (effect-as-plot →
`Catalog::Concept`, routine → `Catalog::Work`, publications → manifestations).

### Research inputs (July 2026, sub-agent reports)

- **Conjuring Archive** — atom = entry-in-publication with typed edges (Inspired
  by/Variations, Related to, Also published here), which map onto Catalog work-to-work
  relationships + the Embodiment M:N. Prop/theme tree, cards = 46% (CA is conjuring-only).
- **Retailers / old-book platforms** — venue + product-type + creator facets; edition
  grouping, curated taxonomy, and *copyright-status reasoning* are the differentiators
  (Catalog + Copyright provide them).
- **The magical arts (authoritative taxonomy)** — FISM, S.A.M., I.B.M. all cut the field
  by **venue first** (Stage vs. Close-up); mentalism/comedy are FISM *sub-categories of
  Stage*, not co-equal top divisions. Umbrella term = **"magic"** (public) / **"the
  conjuring arts"** (scholarly, CARC's wide "and allied arts" scope). "Mystery arts"
  (Burger/McBride; PSYCRETS) is a named genre *cluster* (mentalism + bizarre + psychic +
  hypnosis + readings), not the root. Truly separate sibling umbrellas: stage hypnosis,
  ventriloquism, sideshow, juggling, balloon (the IJA split from the I.B.M. in 1947).
- **Difficulty across the arts** — two agents independently concluded a single universal
  difficulty *scalar* is wrong: "self-working ↔ knuckle-buster" is a conjuring
  manual-dexterity axis that is native to some arts (gambling demo, juggling), renamed &
  revalued in others (escapology's gaffed↔regulation, sideshow's gaff↔real, where hard =
  prestigious/dangerous), **inverted** in comedy/children's (self-working is a *virtue*),
  and **absent** in hypnosis/quick-change. BUT sleight is *shared* (mentalists use center
  tears, billet switches, card work — Osterlind, Maven). The durable model: **a shared
  ordinal scale rated over art-scoped skill dimensions**, plus **universal practicality
  traits** (risk, setup, reset, angles, practice, authenticity) that genuinely span every
  art. Effect taxonomies are **art-scoped** (Fitzkee's object-transformation verbs for
  conjuring; claimed-faculty effects — telepathy, prediction, PK, mediumship — for
  mentalism; the two don't map onto each other).
- **Commerciality** — three orthogonal axes, none a difficulty synonym: **worker-value**
  (worker ↔ exhibition-piece), **fooler** (fools laypeople ↔ fools magicians — *whom* it
  deceives), **reputation-maker** (memorability). ("Flash"/"pipe" are false antonyms —
  flash = accidental exposure.)
- **Presentation-stance** (mentalism/psychic/mystery cluster) — skill-framed (mentalist)
  ↔ genuine-psychic (psychic entertainer) ↔ theatrical-supernatural (mystery performer /
  bizarrist), plus a disclaimer policy (the "mentalist's dilemma"). A framing axis,
  independent of difficulty and effect.

### Orthogonal axes (the design's backbone)

Every axis below is independent; a trick is a point in all of them. This is why the model
decomposes rather than collapsing onto one object:

| Axis | Modeled as |
|---|---|
| **Art / discipline** | `Magic::Art` entity (conjuring, mentalism, …) |
| **Venue** | `Magic::Venue` (close-up, parlour, stage, street, …) — the authorities' primary cut |
| **Category** (prop/theme) | `Magic::Category` tree (cards, coin, rope…) + Concept bridge |
| **Effect** (what appears to happen) | `Magic::Effect`, **art-scoped** |
| **Skill difficulty** | `Magic::SkillRating`s over art-scoped `Magic::SkillDimension`s, on a shared ordinal |
| **Practicality** | `Magic::Practicality` value object (risk, setup, reset, angles, practice, authenticity) |
| **Commerciality** | `Magic::Commerciality` value object (worker, fooler, reputation-maker) |
| **Presentation-stance** | `Magic::PresentationStance` value object (stance, disclaimer) |
| **Exposure** (download gate) | `Magic::Listing.exposure` (public ↔ protected) |

## Tactical DDD in the 37signals idiom

Per the owner: model rich concepts as **entities and value objects under SRP**, use the
**ubiquitous language as class and message names**, and **do not build god-objects** —
`Magic::Trick` is a thin aggregate root that *composes* value objects and *owns* child
entities. Mapping DDD → this Rails app:

- **Value object** = immutable, identity-less, defined by its attributes, with rich
  predicate messages. Implement as `Data.define(...)` PORO in `app/models/magic/`, mapped
  onto columns of its aggregate root via ActiveRecord `composed_of` (`allow_nil: true`).
  VOs answer questions (`practicality.worker_grade?`, `stance.claims_real_powers?`); they
  never persist independently.
- **Entity** = has identity, its own row. Vocabulary entities (Art, Effect, Venue,
  Category, SkillDimension) are reference aggregates; Trick, Listing are the operational
  aggregate roots.
- **Aggregate** = a root AR model + the child rows it owns (`dependent: :destroy`),
  reached only through the root; references to *other* aggregates are by id
  (`belongs_to`), never by ownership. Trick owns its SkillRatings; it *references* Art,
  Effects, Categories, Venues, and `Catalog::Work`.
- House style still applies: string enums via `%w[...].index_by(&:itself)` with
  `validate: true`; capability/behavior in concerns namespaced under the model when a
  root grows; no service layer.

## Entities & aggregates

Namespace module `Magic`, `table_name_prefix "magic_"`. **All FKs use
`foreign_key: { to_table: ... }`** (plan 001's trap).

### Vocabulary aggregate: the arts and their scoped vocabularies

- **`Magic::Art`** (root of the discipline vocabulary): `name` unique. Seed the
  magic-umbrella arts: conjuring, mentalism, psychic_entertainment, mystery_performance,
  escapology, comedy_magic, childrens_magic, manipulation, gambling_demonstration,
  theatrical_pickpocketing, quick_change. The adjacent sibling umbrellas (stage_hypnosis,
  ventriloquism, sideshow, juggling, balloon_modeling) are representable in the same table
  if scope ever grows — a seed/curation choice, not a schema change. `has_many :effects`,
  `has_many :tricks`, `has_many :art_skill_dimensions` + `has_many :skill_dimensions,
  through:`.
- **`Magic::Effect`** (art-scoped effect vocabulary): `belongs_to :art`; `name`; unique
  `[art_id, name]`. Seed conjuring with Fitzkee's verbs (production, vanish, transposition,
  transformation, penetration, restoration, animation, levitation, prediction is
  mental…) and mentalism with claimed-faculty effects (prediction, telepathy,
  clairvoyance, precognition, psychokinesis, mind_influence, mediumship, book_test,
  billet_reading, drawing_duplication, lie_detection, memory_feat, rapid_calculation).
  The two vocabularies deliberately overlap only where the arts genuinely do (ACAAN).
- **`Magic::SkillDimension`** (the named difficulty axes): `name` unique (sleight, memory,
  scripting, nerve, cold_reading, outs, …). **M:N with Art** via
  **`Magic::ArtSkillDimension`** (`art` + `skill_dimension`, unique pair) — because
  `sleight` spans conjuring/mentalism/gambling and `scripting` spans
  mentalism/comedy/mystery. This is the literal encoding of "shared facet set, art-specific
  relevance."
- **`Magic::Venue`** — `name` unique. Seed: close_up, parlour, stage, street, walk_around,
  virtual.
- **`Magic::Category`** — hierarchical tree: `name`, `parent` (self-FK, nullable), optional
  `concept` (FK → catalog_concepts, the Group-3 bridge). Unique `[parent_id, name]`.
  Methods `path`, `self_and_descendants` (SQLite `WITH RECURSIVE`). Seed CA's prop/theme
  shape.

### Operational aggregate: `Magic::Trick` (root) — a routine's domain assessment

Thin root; identity + references + composed value objects + owned skill ratings.

| column | notes |
|---|---|
| work (FK → catalog_works, unique) | the routine's Work |
| art (FK → magic_arts) | its discipline — scopes valid effects & skill dimensions |
| summary | string — CA-style one-liner |
| *practicality columns* | `risk`, `setup`, `reset`, `angles`, `practice`, `authenticity` (→ Practicality VO) |
| *commerciality columns* | `worker` (bool), `audience_fooled`, `reputation_maker` (bool) (→ Commerciality VO) |
| *stance columns* | `stance`, `disclaimer` (nullable; → PresentationStance VO) |

Associations & composition:

```ruby
class Magic::Trick < ApplicationRecord
  belongs_to :work, class_name: "Catalog::Work"
  belongs_to :art

  has_many :skill_ratings, dependent: :destroy      # owned children (the difficulty vector)
  has_many :skill_dimensions, through: :skill_ratings

  has_many :trick_categories, dependent: :destroy
  has_many :categories, through: :trick_categories
  has_many :trick_effects, dependent: :destroy
  has_many :effects, through: :trick_effects
  has_many :trick_venues, dependent: :destroy
  has_many :venues, through: :trick_venues

  composed_of :practicality,  class_name: "Magic::Practicality",
    mapping: %w[ risk setup reset angles practice authenticity ].map { [ it, it ] },
    allow_nil: true
  composed_of :commerciality, class_name: "Magic::Commerciality",
    mapping: [ %w[worker worker], %w[audience_fooled audience_fooled], %w[reputation_maker reputation_maker] ],
    allow_nil: true
  composed_of :stance, class_name: "Magic::PresentationStance",
    mapping: [ %w[stance stance], %w[disclaimer disclaimer] ], allow_nil: true

  # ubiquitous-language reads that delegate to the value objects / children
  def worker?          = commerciality&.worker?
  def fools_magicians? = commerciality&.fools_magicians?
  def related_tricks   = ... # via Catalog work-to-work relationships, mapped back to tricks

  validate :effects_within_art, :skill_ratings_within_art
end
```

- **`Magic::SkillRating`** (owned child entity — the difficulty vector): `belongs_to
  :trick`, `belongs_to :skill_dimension`, `level` enum `%w[ none low moderate high extreme
  ]` (the **shared ordinal**, comparable across arts). Unique `[trick_id,
  skill_dimension_id]`. For the sleight dimension the community labels map onto the ordinal
  (`self_working`≈none/low, `knuckle_buster`≈extreme) — documented, not a separate scale,
  so cross-art queries ("show me low-skill tricks in any art") work. Validation
  (`skill_ratings_within_art`): a rating's dimension must be linked to the trick's art via
  ArtSkillDimension.

### Value objects (immutable, `Data.define`, ubiquitous messages)

```ruby
# app/models/magic/practicality.rb — "can I actually work this, and how risky?"  (cross-art)
Magic::Practicality = Data.define(:risk, :setup, :reset, :angles, :practice, :authenticity) do
  RISK    = %w[ none minor moderate severe lethal ].freeze
  SETUP   = %w[ impromptu light involved elaborate ].freeze
  RESET   = %w[ instant quick involved impractical ].freeze
  ANGLES  = %w[ angle_proof forgiving frontal_only angle_sensitive ].freeze
  PRACTICE = %w[ minutes hours weeks months years ].freeze
  AUTHENTICITY = %w[ real gaffed hybrid ].freeze     # real feat vs gimmick — matters in escapology/sideshow

  def impromptu?   = setup == "impromptu"
  def angle_proof? = angles == "angle_proof"
  def gaffed?      = authenticity == "gaffed"
  def dangerous?   = %w[ severe lethal ].include?(risk)
end
```

```ruby
# app/models/magic/commerciality.rb — "how does it play commercially and among peers?"
Magic::Commerciality = Data.define(:worker, :audience_fooled, :reputation_maker) do
  AUDIENCE_FOOLED = %w[ laypeople magicians both ].freeze   # the "fooler" axis: whom it deceives

  def worker?          = !!worker
  def fools_magicians? = %w[ magicians both ].include?(audience_fooled)
  def reputation_maker? = !!reputation_maker
end
```

```ruby
# app/models/magic/presentation_stance.rb — the mind/mystery framing (nullable elsewhere)
Magic::PresentationStance = Data.define(:stance, :disclaimer) do
  STANCE     = %w[ skill_framed genuine_psychic theatrical_supernatural ].freeze
  DISCLAIMER = %w[ none implicit explicit ].freeze         # the "mentalist's dilemma" policy

  def claims_real_powers? = stance == "genuine_psychic"
end
```

The plain enum columns still carry `enum ..., validate: true` on `Magic::Trick` for the
scale vocabularies (`enum :risk, Magic::Practicality::RISK.index_by(&:itself), prefix:
true`, etc.) so DB values stay legible and invalid values fail validation; the VOs add the
behavior and cohesion on top. (`composed_of` is the idiomatic Rails value-object seam; if
it feels heavy later, a Rails 7 custom `attribute` type is the fallback — same VO class.)

### Operational aggregate: `Magic::Listing` (root) — the public book view

| column | notes |
|---|---|
| work (FK → catalog_works, unique) | book-level work |
| exposure | enum `%w[ public protected ]`, default `public` |
| featured | boolean, default false — homepage/search boost (*Greater Magic*) |
| blurb | text |

- `accessible_to?(user)` = `public_exposure? || user&.can_access_protected?` — the entire
  download gate, one predicate, exhaustively tested. `public` = safe to expose to
  laypeople (early Tarbell); `protected` = exposes methods working magicians still rely on
  (grounded in the joint 1993 I.B.M. & S.A.M. Code of Ethics, clause 1). Drives plan 004's
  `print_budget` step (public marketplaces only for `public` titles). Independent of the
  Trick axes — a book of self-working tricks can still be `protected`.
- **`Magic::PurchaseLink`** (owned child): `belongs_to :listing`, `label`, `url` (presence
  only), `position`. Affiliate/commerce, incl. countdown pages for not-yet-PD works.

Value objects (`practicality.rb`, `commerciality.rb`, `presentation_stance.rb`) are
hand-authored POROs — no generator, no migration.

Hand-edits: every `references` → `foreign_key: { to_table: :magic_* }` (or
`:catalog_works` / `:catalog_concepts`); `art`/`concept`/`parent` nullable where noted
(`parent` self-ref → `:magic_categories`); unique indexes: `magic_arts.name`,
`[art_id,name]` on effects, `magic_skill_dimensions.name`, `[art_id,skill_dimension_id]` on
art_skill_dimensions, `magic_venues.name`, `[parent_id,name]` on categories,
trick.work_id, listing.work_id, `[trick_id,skill_dimension_id]` on skill_ratings, and the
three trick-join pairs; enum columns `null:` per default (`exposure` default "public").

## Tests

- **Download gate matrix** (most important): royal_road accessible to nil/visitor/
  magician/kerrick; greater_magic (protected) denied to nil & visitor, allowed to
  vetted_magician & kerrick.
- **Art-scoped integrity**: a trick's effect must belong to its art (`effects_within_art`
  rejects a mentalism effect on a conjuring trick); a skill rating's dimension must be
  linked to the trick's art (rejects `cold_reading` on a pure conjuring trick unless
  linked).
- **Difficulty vector, cross-art**: `center_tear_prediction.skill_ratings` spans
  sleight+nerve+scripting+cold_reading; a cross-art query `SkillRating.where(level:
  %w[none low])` returns low-skill tricks regardless of art; the sleight dimension is
  shared (both fixture arts link it via ArtSkillDimension).
- **Value objects**: `practicality.impromptu?`/`angle_proof?`/`gaffed?`/`dangerous?`;
  `commerciality.worker?`/`fools_magicians?`; `stance.claims_real_powers?`; `composed_of`
  round-trips columns ↔ VO; VO is immutable (`Data`); enum validation rejects out-of-scale
  values on the trick.
- **Vocabulary**: Art/Effect/SkillDimension/Venue name uniqueness; effect `[art,name]`
  uniqueness; Category `path`/`self_and_descendants`/concept bridge; ArtSkillDimension pair
  uniqueness.
- **Listing/PurchaseLink**: one listing per work; exposure vocabulary; url presence;
  position ordering. **Trick**: one per work; `related_tricks` delegation via Catalog
  relationships.
