# Plan 003: Copyright Bounded Context (Model Layer)

## Context

The Copyright context answers "what is this work's US copyright status, and how do we
prove it?" for Project Gutenberg clearance (Rules 1 and 6 now; schema doesn't rule others
out). Source materials: PG's copyright rules, the copy.pglaf.org submission form (field
capacities included below — they become validations), the clearance status page (real
example: Request ID 87848, *The Royal Road to Card Magic*, "Cleared OK", OK key
`20250510173922hugard`), and the Rule 6 dossier `tmp/rrtcm_rule6.md`.

Key requirements from the domain owner:

- The Rule 6 dossier is **structured data** (entities/value objects), with the markdown
  document PG receives generated as a *report* of that data — not a text blob.
- "Failure isn't a thing — it's just how far it goes": no dead-end states.
- **The countdown is a big deal**: a work with a known first-publication year has a
  computable Rule 1 public-domain date, including *future* dates (*Greater Magic* hype,
  affiliate links for not-yet-PD works). Even a book published tomorrow can be tracked
  with a 95-year countdown.
- Researcher attribution from day one (plan 002's `User` + `can_research?`); Kerrick is
  the only researcher until volunteers are vetted.

DDD placement: researched biographical facts (nationality, domicile, heirs, aliases
*with per-claim sources*) live HERE, not on `Catalog::Agent`. Copyright references
Catalog by ID. Two-level split:

- **`Copyright::Determination`** — the status/countdown answer for a copyrightable
  unit (see below).
- **`Copyright::Clearance`** — per `Catalog::Manifestation`: one PG clearance request
  lifecycle for *the actual book being digitized* (PG's own rule: research the actual
  copy, not other editions).

### Ubiquitous language: U.S. copyright law, with PG as a conformist seam

This context speaks the language of **17 U.S.C. and the U.S. Copyright Office** —
work (of authorship), publication, registration, renewal, notice, claimant, term,
national/domiciliary, public domain. Project Gutenberg *adopts* that language and adds
its own operational layer (rule numbers, "clearance," OK keys); the PG layer is an
integration seam, not the context's core vocabulary. Concretely:

- Core entities (Determination, Dossier and its research records, renewals,
  registrations, claimants) use statutory vocabulary. The **basis** of a determination
  is the legal ground, not a PG rule number:

  ```ruby
  BASES = %w[ term_expired nonrenewal lack_of_notice us_government_work
              unrestored_foreign life_plus_seventy corporate_term
              pre_1978_unpublished ].freeze
  # Translation to PG's operational shorthand lives at the seam:
  PG_RULES = { "term_expired" => "1", "life_plus_seventy" => "2",
               "corporate_term" => "3", "pre_1978_unpublished" => "4",
               "lack_of_notice" => "5", "nonrenewal" => "6",
               "us_government_work" => "8", "unrestored_foreign" => "10" }.freeze
  ```

- The PG-facing exchange objects — `Clearance` and its children, and
  `Dossier::Report` — deliberately **conform to PG's vocabulary and form layout**
  ("Publishings", role option strings, field capacities), because their entire job is
  to speak PG's dialect at the boundary. That conformity stops at those objects.

### "Work" is a false friend across this seam

FRBR's work is the abstract creation; the U.S. Copyright Office's "work" is a unit of
*authorship* — much closer to a specific published edition. PG states the consequence
explicitly: "Each edition of a work may have its own period of copyright restriction…
Every translation has independent copyright." Scot's 1584 text is public domain while a
1930 scholarly introduction is not — one FRBR work-family, many USCO works.

So a Determination anchors to a Catalog work **plus an optional manifestation scope**:
`manifestation_id` NULL means "the original text as first published" (the common case,
and what the countdown feature reads); present means "the identified edition's added
authorship" (revised editions, translations, introductions — each its own USCO work
with its own clock). Uniqueness: unique `[work_id, manifestation_id]` plus a partial
unique index on `work_id WHERE manifestation_id IS NULL` (SQLite treats NULLs as
distinct in ordinary unique indexes, so the partial index is required to enforce
one unscoped determination per work).

## Entities

Namespace module `Copyright` with `table_name_prefix "copyright_"` (generated by the
first `g model copyright/...`). **All FKs use `foreign_key: { to_table: ... }`** (plan
001's trap).

### `Copyright::Determination` (per copyrightable unit — see "false friend" above)

| column | notes |
|---|---|
| work (FK → catalog_works) | |
| manifestation (FK → catalog_manifestations, nullable) | NULL = original text as first published; present = that edition's added authorship |
| status | enum `%w[ unknown researching determined ]` |
| basis | enum `BASES` (statutory grounds, above), nullable until determined; `pg_rule` derived via `PG_RULES` |
| first_publication_year | string (EDTF-friendly, matches Catalog date style) |
| first_publication_country | string (2-letter) |
| initial_registration_number | string — CCE registration ("A20124", "A184118"); drives Phase 3 searches |
| public_domain_on | date, nullable — **may be future** (the countdown) |
| notes | text |

Behavior (model methods / PORO):

- `Copyright::Determination::TermExpiration` PORO (the pre-1978 95-year publication
  term — PG's "Rule 1" at the seam): for pre-1978 first US publication year Y,
  `public_domain_on = Date.new(Y + 96, 1, 1)` (published 1930 → PD 2026-01-01).
  `apply!` sets basis `term_expired`/status/public_domain_on when Y ≤ 1977.
- `public_domain?` = `public_domain_on&.past?`; `countdown_days` =
  `(public_domain_on - Date.current).to_i` when future. (No `Date.current` in
  fixtures/tests without freezing time — use `travel_to`.)

### `Copyright::Clearance` (one PG request per manifestation)

Form-mirror columns with **length validations matching PG's database capacities**
(PG silently truncates; we validate instead): title(600), subtitle(600),
language_code(2), notes(6000), publisher_name(240), publication_city(60),
publication_country(30), source_notes(6000), scans_archive_urls(1600),
wikipedia_urls(1600).

| column | notes |
|---|---|
| manifestation (FK → catalog_manifestations) | the actual book digitized |
| determination (FK → copyright_determinations) | |
| researcher (FK → users) | `belongs_to :researcher, class_name: "User"` |
| status | enum `%w[ drafting submitted iterating cleared withdrawn ]` |
| ...form-mirror columns above... | |
| pg_request_id | string — e.g. "87848" |
| pg_rule_applied | string — e.g. "OK: Rule 6" (as PG renders it) |
| pg_ok_key | string — e.g. "20250510173922hugard" (the upload key) |
| submitted_at, cleared_at | datetimes |

- `has_many :authors` (`Copyright::ClearanceAuthor`), `has_many :publishings`
  (`Copyright::ClearancePublishing`), `has_many_attached :page_scans`.
- Validations: ≤ 5 authors, ≤ 4 publishings, ≤ 4 page scans (jpg/gif/png/txt) — PG form
  limits. Scan size: PG's prose says 10 MB max per file but the form's hidden
  `MAX_FILE_SIZE` is 5,000,000 — validate ≤ 5 MB to guarantee the immediate-upload path
  works. Page scans are title/verso images, small enough for Active Storage (unlike the
  80 GB scan sets, which never touch this app — see plan 004).
- These are deliberate **snapshots**, not live joins to Catalog: the submission must
  record what was sent, even if Catalog data is later corrected.

### `Copyright::ClearanceAuthor` (≤ 5 per clearance)

clearance FK; position:integer; first_name(150), last_name(150); role — enum mapping
snake_case keys to **PG's literal option text** (from the form's role select, verified
against the live form HTML), so predicates are clean and the stored/submitted value is
exactly what PG expects:

```ruby
ROLES = {
  author_creator: "Author/Creator", editor: "Editor", translator: "Translator",
  illustrator: "Illustrator", compiler: "Compiler", annotator: "Annotator",
  commentator: "Commentator", performer: "Performer", photographer: "Photographer",
  engraver: "Engraver", artist: "Artist", contributor: "Contributor",
  unknown_role: "Unknown role"
}.freeze
enum :role, ROLES.transform_values(&:to_s), validate: true
```

Real example: Hugard/Braué Author/Creator, Fleming Commentator, Rigney Illustrator.

### `Copyright::ClearancePublishing` (≤ 4 per clearance)

clearance FK; position:integer; year(20):string; kind — enum, same literal-text
mapping, from the form's complete "Type" select:

```ruby
KINDS = {
  copyright_notice: "Copyright notice or similar",
  no_copyright_notice: "No copyright notice (just publication date)",
  reprint_or_facsimile: "Reprint or facsimile"
}.freeze
```

### The Rule 6 dossier (structured research on a determination)

- **`Copyright::Dossier`**: determination FK, researcher FK (users), status enum
  `%w[ in_progress complete ]`. `Copyright::Dossier::Report` PORO renders the
  submission markdown from the records below (mirroring `tmp/rrtcm_rule6.md`'s
  structure: Basic Information → Phase 1 Biographical → Phase 2 Bibliographical →
  Phase 3 Renewal).
- **`Copyright::AuthorResearch`**: dossier FK; agent FK → catalog_agents (optional —
  links the researched person to the catalog identity); name; **role** (reuse
  `ClearanceAuthor::ROLES` keys, default `author_creator` — Rule 6 requires researching
  ALL creators, and the completed dossier researches a commentator and an illustrator,
  not just authors); us_status enum `%w[ national domiciliary neither unknown ]` (the
  statute's words — 17 U.S.C. speaks of a "national or domiciliary of the United
  States"; PG's "citizen/resident" paraphrases them); basis (text); birth_date/
  death_date (strings); heirs (text).
- **`Copyright::AliasFinding`**: author_research FK; name; kind enum
  `%w[ birth spelling stage performance pen married maiden ]` (the dossier's observed
  types); note. Overlaps `Catalog::Nomen` *by design* — this context's aliases carry
  evidence and exist to drive renewal searches; confirmed ones can be copied into
  Catalog as nomens by a Librarian.
- **`Copyright::Republication`**: dossier FK; title; year:string; publisher;
  **edition_designation** ("2nd Edition", "Third Printing" — the in-progress dossiers
  track these); **access_status** enum `%w[ examined accessible inaccessible ]`,
  nullable (an edition "out of my reach because of its rarity" is a real, reportable
  research limitation); notes (the "how closely do republications match" comparison PG
  requires). Rule 6 needs *every* edition ever; the 4-year renewal window logic reads
  these.
- **`Copyright::RenewalSearch`**: dossier FK; resource (e.g. "Stanford Copyright
  Renewals", "PG #11800", "copyright.gov"); terms; searched_on:date; **status** enum
  `%w[ planned clean interesting found_renewal ]` (the dossiers' ✅/⚠️/‼️ outcome
  markers — the Report needs them to regenerate the search matrix, and "planned"
  captures in-progress research); outcome (text). One row per search performed — PG
  requires reporting the searches themselves, including empty ones.
- **`Copyright::RenewalRecord`**: renewal_search FK; registration_number ("A20124"),
  renewal_number ("R410430"), holder, applies:boolean, assessment (rich text). Found
  renewals — including ones judged not to apply (e.g. Myra C. Benson's renewal of
  *Modern Magic Manual*, a different work).
- **`Copyright::CopyrightClaim`**: dossier FK; claimant_name; basis (text). Third
  parties asserting rights beyond heirs — the Trick Brain dossier records "Magic Box
  Productions claimed 'Full permission granted us from Lee Jacobs Productions'". These
  are researched claims needing citations, not free text buried in `heirs`.
- **`Copyright::Finding`**: dossier FK; section enum
  `%w[ basic biographical bibliographical renewal ]`; question:string; answer:text;
  position:integer. The catch-all for the standard PG questionnaire's prose answers —
  including **explicit negative findings** ("I found no evidence that it was part of a
  serial"), which document research completeness and must appear in the report. The
  structured entities above carry the queryable data; Findings carry the narrative.
- **`Copyright::Citation`**: polymorphic `citable` (author_research, alias_finding,
  republication, renewal_record, copyright_claim, finding, ...); url; quote;
  accessed_on:date. The per-claim evidence pattern — the dossier cites multiple sources
  per claim, so this is a first-class table, not inline columns. `has_many :citations,
  as: :citable` on each research record.

Considered and rejected: a `Copyright::Series` entity for "Book Two of The Fitzkee
Trilogy." Series membership is bibliographic structure that Catalog already owns (work
relationships, series statements); the Report reads it across the seam, and a
researcher can note it in a Finding before Catalog data exists. Per-phase dossier
status was also considered: the binary `in_progress|complete` stands for now — phase
completeness is derivable from Findings/searches, and the in-progress dossiers' "TODO"
markers map to `planned` searches and missing Findings.

Rich-text fields use Action Text (`has_rich_text`) only if formatting is wanted;
otherwise plain `text` columns. Default: plain text (the dossiers are markdown-native).

## Context seams

- Reads Catalog by ID (work, manifestation, agent). Writes nothing to Catalog; a
  Librarian may copy confirmed aliases into `Catalog::Nomen` manually.
- **Workflow** (plan 004) gates on `Determination#public_domain?` /
  `Clearance#cleared?` and drives status transitions; the countdown feeds the public
  Magic UI (plan 005) for "coming to public domain" features and affiliate links.
- The `Dossier::Report` markdown + clearance form fields + page scans together are
  exactly the copy.pglaf.org submission payload.
