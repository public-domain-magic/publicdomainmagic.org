# Plan 005: Magic Bounded Context (Model Layer)

## Context

Magic is the public-facing domain context: search/browse of the library, the access
rules for downloads, and the commerce hooks (affiliate links, the *Greater Magic*
countdown hype). All data is hand-entered by Librarians at launch — one Librarian, for
now. It references Catalog by ID; the FRBR mapping is the context map at
`.agents/skills/frbr-wemi/references/magic.md`.

**Scope discipline (owner decisions):**

- PDM is a *library*, not a trick index — we are not competing with Conjuring Archive.
  Launch models the **book level**: what can be found, what can be downloaded by whom,
  and what can be bought.
- For classification, take the industry-standard shortcut honestly: **flat Tags**, not a
  bespoke category tree. The taxonomy research (see
  `doc/contributors/magic-taxonomy-research.md`) proved the "right" taxonomy is
  genuinely contested (venue-first per FISM vs. prop/theme per Conjuring Archive);
  tags defer those decisions while still capturing the raw material.
- Trick-level knowledge is *not* launch-critical but **will accrue accidentally** — the
  magicians converting books are curious folks and will note effects, sleights, and
  venues as they work. Tags are where that folksonomy lands (taggings are polymorphic,
  so tags attach to Listings now and to component works/tricks later). The future
  rigorous model is seeded by tag mining, per the research doc.

## Entities

Namespace module `Magic`, `table_name_prefix "magic_"` (generated by the first
`g model magic/...`). **All FKs use `foreign_key: { to_table: ... }`** (plan 001's trap).

### `Magic::Listing` (aggregate root) — the public book view

| column | notes |
|---|---|
| work (FK → catalog_works, unique) | book-level work |
| exposure | enum `%w[ public protected ]`, default `public` |
| featured | boolean, default false — homepage/search boost (*Greater Magic*) |
| blurb | text |

- `accessible_to?(user)` = `public_exposure? || user&.can_access_protected?` — the
  entire download gate, one predicate, exhaustively tested. `public` = safe to expose to
  laypeople (early Tarbell); `protected` = exposes methods working magicians still rely
  on (grounded in the joint 1993 I.B.M. & S.A.M. Code of Ethics, clause 1). Drives plan
  004's `print_budget` step (public marketplaces only for `public` titles).
- `has_many :purchase_links`; `has_many :taggings, as: :taggable` + `has_many :tags,
  through: :taggings`.

### `Magic::PurchaseLink` (owned child)

`belongs_to :listing`; `label` (presence); `url` (presence only — dealer/affiliate URLs
take many shapes); `position:integer`. Affiliate/commerce, incl. countdown pages for
not-yet-PD works (the Copyright seam supplies `countdown_days`).

### `Magic::Tag` — flat classification vocabulary

`name` (presence, unique, normalized: `normalizes :name, with: ->(n) {
n.strip.downcase }`); optional `concept` (FK → catalog_concepts, nullable) — the Group 3
bridge, so tag search can reach works whose bibliographic *subjects* match even before
they're tagged. No hierarchy, no kinds, no axes: "cards", "self-working", "close-up",
"ambitious card" all coexist. Tag gardening (merging, concept-linking, promotion into
future vocabularies) is a Librarian activity, not schema.

### `Magic::Tagging` (join, polymorphic)

`belongs_to :tag`; `belongs_to :taggable, polymorphic: true` (Listing today; Trick or
`Catalog::Work` components later). Unique `[tag_id, taggable_type, taggable_id]`.

## Generators

```sh
bin/rails g model magic/listing work:references exposure:string featured:boolean blurb:text
bin/rails g model magic/purchase_link listing:references label:string url:string position:integer
bin/rails g model magic/tag name:string concept:references
bin/rails g model magic/tagging tag:references 'taggable:references{polymorphic}'
```

Hand-edits: `work` → `foreign_key: { to_table: :catalog_works }` + unique index;
`concept` → `to_table: :catalog_concepts`, **nullable**; `listing`/`tag` refs →
`to_table: :magic_*`; polymorphic `taggable` gets no DB FK; `exposure` null: false
default "public"; `featured` null: false default false; `name`/`label`/`url` null:
false; unique index on `magic_tags.name` and on `[tag_id, taggable_type, taggable_id]`
(explicit `name:` — the auto-generated composite name exceeds 62 chars).

## Fixtures

- `listings.yml`: `royal_road` (public, featured false); `greater_magic` (protected,
  featured true — the countdown/commerce case); `discoverie` (public).
- `purchase_links.yml`: greater_magic → one dealer link (position 1).
- `tags.yml`: `cards`, `sleights`, `cups_and_balls` (concept: cups_and_balls — the
  bridge), `self_working` (name "self-working" — proves normalization keeps the hyphen,
  lowercases, strips).
- `taggings.yml`: royal_road ← cards + sleights; discoverie ← cups_and_balls.

Requires plan 001's catalog fixtures (royal_road, discoverie, concepts) and plan 003's
greater_magic work. Users from plan 002 (kerrick, vetted_magician, visitor).

## Tests

- **Download gate matrix** (most important): royal_road (public) accessible to
  nil/visitor/vetted_magician/kerrick — all true; greater_magic (protected) denied to
  nil & visitor, allowed to vetted_magician (via `can_access_protected?`) & kerrick
  (librarian). One listing per work; exposure vocabulary (`enum validate: true`).
- **Tag**: name presence + uniqueness; normalization (`"  Cards "` → `"cards"`, and the
  normalized duplicate collides with the existing `cards` tag); concept bridge resolves
  to `catalog_concepts(:cups_and_balls)`; concept optional.
- **Tagging**: uniqueness per (tag, taggable); `listing.tags` round-trip; polymorphism
  (tag a second taggable type — e.g. a `Catalog::Work` — proving the accidental
  trick-data path stays open).
- **PurchaseLink**: label/url presence; position ordering scope.

## Context seams

- **Catalog**: listing.work / tag.concept — read-only references. Work-grouped search
  results, edition lists, and creator pages read Catalog; Magic adds no bibliographic
  data of its own.
- **Copyright**: listing pages read `Determination#public_domain?` / `countdown_days`
  for status badges, countdown pages, and affiliate timing.
- **Workflow**: `Project#downloadable?` + external `Resource` links gate the download
  button together with `Listing#accessible_to?`.
- **Users** (plan 002): `can_access_protected?` is the only identity fact Magic
  consumes.
